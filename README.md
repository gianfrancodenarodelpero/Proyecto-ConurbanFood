📌 Descripción del proyecto

ConurbanFood es un proyecto orientado a la gestión de Seguridad e Higiene dentro de un entorno de producción alimentaria.

La propuesta consiste en desarrollar una herramienta digital que permita centralizar información sobre sustancias químicas, facilitar el acceso a sus hojas de datos de seguridad (SDS), consultar procedimientos de actuación ante emergencias y mejorar el seguimiento de incidentes dentro de una planta de producción.

El objetivo principal es promover un entorno de trabajo más seguro mediante el acceso rápido a información relevante y la organización de los procedimientos de prevención y respuesta.

🎯 Objetivos

Centralizar la información de seguridad de las sustancias utilizadas en planta.

Facilitar el acceso a las hojas de datos de seguridad.

Agilizar la identificación de sustancias mediante códigos QR.

Proporcionar instrucciones de actuación ante derrames, fugas y accidentes.

Organizar la gestión de usuarios según sus roles.

Facilitar el seguimiento de incidentes y auditorías.

Mejorar la supervisión de las condiciones de seguridad de la planta.

⚙️ Funcionalidades principales

🔐 Gestión de usuarios y roles

El prototipo contempla diferentes perfiles de acceso:

Operario.

Supervisor.

Técnico de Seguridad e Higiene.

Administrador.

Cada perfil cuenta con una perspectiva diferente del sistema.

📱 Identificación mediante códigos QR

Permite simular la lectura de códigos QR asociados a sustancias químicas para acceder rápidamente a su información de seguridad.

🧪 Hojas de datos de seguridad (SDS)

Incluye una sección de consulta con información relevante sobre:

Identificación de sustancias.

Clasificación de peligros según el SGA.

Pictogramas de seguridad.

Primeros auxilios.

Procedimientos ante derrames y fugas.

🚨 Gestión de emergencias

Contempla procedimientos de actuación ante situaciones de riesgo, incluyendo:

Derrames y fugas de sustancias.

Contacto accidental con productos químicos.

Utilización de elementos de protección personal (EPP).

Acciones iniciales de respuesta ante emergencias.

📊 Panel de supervisión

Incluye indicadores y elementos de seguimiento para visualizar:

Estado de la planta.

Días sin incidentes.

Hojas de seguridad pendientes de actualización.

Incidentes abiertos.

Registro de auditoría.

🛠️ Administración

Contempla una sección para la gestión de usuarios, roles y materias primas asociadas al sistema.

🖥️ Tecnologías utilizadas

El prototipo navegable está desarrollado utilizando tecnologías web:

HTML5: estructura de la aplicación.

CSS3: diseño visual, estilos y adaptación a diferentes pantallas.

JavaScript: navegación e interacciones del prototipo.

No requiere la instalación de frameworks ni dependencias adicionales para visualizar la versión actual.
